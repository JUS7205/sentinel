# Security Policy

## Reporting a Vulnerability

This project is a portfolio / educational capability showcase. It is **not** deployed
in production and is not intended for production use without review.

If you believe you have found a security issue in this codebase:

- **Do not** open a public issue or discussion.
- Report it privately via GitHub's vulnerability reporting flow:
  <https://github.com/JUS7205/REPO/security/advisories/new>
- Include a minimal reproducer and, if possible, a suggested fix.

Reports are reviewed as availability permits; please do not expect an SLA.
